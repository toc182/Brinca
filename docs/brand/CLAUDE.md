# Brand — Brinca

Brand identity, voice, and all bilingual user-facing copy.

- For visual specs (tokens, components, mascot visual), see `docs/design-system/`.
- For app behavior and interaction patterns, see `docs/ux/`.

---

## When to reference

Open the relevant file when:
- Writing or reviewing any user-facing string → `microcopy.md`
- Choosing tone or register for a new screen → `personality.md`
- Spec'ing an empty state → `empty-state-copy.md` (and `design-system/components/empty-state.md` for the layout)
- Anything trademark / domain / pre-launch related → `name.md`, `pre-launch.md`

---

## Files

| File | Topic |
