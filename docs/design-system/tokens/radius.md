# Border radius

**Implementation:** values live in `src/shared/theme.ts`.

---

## Tokens

| Token | Value | Use |
|---|---|---|
| `radiusXs` | 4 | Chips, small tags, badges (adult) |
| `radiusSm` | 8 | Small cards |
| `radiusMd` | 12 | Cards, toasts, buttons (adult), modals inner |
| `radiusLg` | 16 | Sheets, hero cards, modal top corners |
| `radiusXl` | 24 | Kid celebration cards, achievement tiles |
| `radiusFull` | 9999 | Avatars, pills, kid-view CTA buttons |

---

## Standard rules

- **Buttons:** `radiusFull` for kid CTAs (pill shape), `radiusMd` for adult buttons.
