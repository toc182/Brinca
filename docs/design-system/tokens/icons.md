# Icons — Phosphor

**Library:** `phosphor-react-native` v3 (1,200+ icons, 6 weights including Duotone).

---

## Default stroke

1.5pt Regular weight.

---

## Weight variants

| Weight | When |
|---|---|
| Regular | Default |
| Bold | Active tabs |
| Duotone | Achievements and kid-hero surfaces only |
| Fill | Destructive actions, status badges |

> **Duotone rule:** reserved for achievement icons and kid-hero surfaces. Never use on adult data surfaces.

---

## Standard sizes

| Size | Use |
|---|---|
| 16 | Inline |
| 20 | Body, list, toast |
| 24 | Tab bar, navigation |
| 32 | Large actions, adult empty states |
| 48 | Kid tiles, celebrations |
