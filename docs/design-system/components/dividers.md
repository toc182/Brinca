# Dividers & separators

| Use case | Thickness | Color | Inset |
|---|---|---|---|
| List row (text only) | `hairlineWidth` | `border-subtle` | 16pt leading |
| List row (avatar/icon) | `hairlineWidth` | `border-subtle` | 56pt leading |
| Between groups | 1pt | `border-default` | Full width |
| Section header | 1pt | `border-default` | Full width |
| Within form | `hairlineWidth` | `border-subtle` | Full width |
| Card internal | `hairlineWidth` | `border-subtle` | Full width |

**Kid views:** prefer card-based grouping with 12pt gaps over dividers.
