# Empty state

Shown on any screen that can have no data. Never show a blank screen.

**Structure:** illustration + short title + body + optional CTA.

**Copy:** Capi expression and bilingual title/body per context lives in `docs/brand/empty-state-copy.md`.

---

## Layout

Vertical stack, centered, padding `lg` (24), gap `md` (16).

| Element | Value |
|---|---|
| Illustration size | 180pt default, 200pt kid hero, 160pt adult-dense |
| Title | Fredoka 20/28, weight 700, `text-primary`, centered |
| Body | Lexend 15/22, weight 400, `text-secondary`, centered, maxWidth 320 |
| CTA | `primary-500` bg, white text, `radiusFull` kid / `radiusMd` adult, 48pt adult / 56pt kid |

---

## Adult clinical / data screens

Use a Phosphor duotone icon at 48pt instead of Capi.
